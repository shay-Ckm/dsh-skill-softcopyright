# AIGC 检测平台与查重方式（资源库）

> 降 AIGC 工作流中"实测环节"使用的平台与配合方式。静态检测（check_aigc.py）清共性
> 问题，实测平台抓"语言顺滑度"，两者互补。**最终以实测平台报告为准**。

---

## 一、常用检测平台与特点

| 平台 | 检出形式 | 配合要点（实测） |
|------|---------|-----------------|
| **PaperPass** | 按段分级标红：轻度/中度/重度疑似 AIGC | 报告可复制标红段落文本，直接驱动第三轮精修；注意报告贴文与 docx 文本有空格差异 |
| 知网 AIGC 检测 | 全文疑似率 + 段落级标记 | 论文场景常用；软著场景也接受 |
| 维普 AIGC 检测 | 疑似率 + 标红 | 与知网互补，可交叉验证 |
| 格子达 / PaperYY 等 | 疑似率报告 | 免费额度多，可先跑一版摸底 |

> 注：各平台算法细节会更新，具体阈值/分级以平台当期为准；上表只记录**工作流配合方式**。

## 二、建议检测流程（与改写轮次配合）

```
1. 第一轮改写完成（词汇级）→ 交付 _降AIGC版.docx → 用户跑一次平台实测
2. 第二轮结构检查完成（句式级，静态）→ 若实测仍有标红进入第 3 步
3. 第三轮：按标红报告逐段精修 → 交付 _降AIGC版_V2.docx → 用户复测
4. 循环直至：无重度/中度标红（术语密集的算法原理段可接受轻度）
```

## 三、实测判读规则

- **重度标红**：必改（多为排比列举、模板句式、长句完整度过高的功能描述段）。
- **中度标红**：优先改；若为术语密集的算法/公式段，改写空间有限，可接受或做轻量调整。
- **轻度标红**：一般是术语定义段、参数枚举段（如"该参数用于…"），属规范表达，可保留。
- **复测验证**：同一平台前后对比，重点看重度/中度是否消失、疑似率是否下降。

## 四、与静态检测的分工

| 手段 | 作用 | 局限 |
|------|------|------|
| check_aigc.py（词汇+结构） | 清 AI 高频词、21 类句式结构，可量化降幅 | 抓不到"语言顺滑度/完整度"这类统计特征 |
| 实测平台（PaperPass 等） | 抓真实检出结果，分级标红 | 需要用户操作、按次计费/耗时 |

**结论**：静态检测做前置清扫（改一轮省一轮实测），实测平台做最终验收与标红定位。
